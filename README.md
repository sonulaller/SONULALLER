## About Me

- I taught myself web development and now build complete websites end-to-end: frontend, backend, database, SEO and deployment.
- My first complete project was the **NLSP School website**, with admissions, an AI chatbot and a full SEO pass.
- I also build small browser games for fun and practice.
- I built my own **portfolio with a custom admin panel**, so I can update projects, images and content without touching code.
- Based in Kasan, Kaithal, Haryana.

## How I Work

1. **Understand first.** I clarify what the project needs before writing code.
2. **Build end-to-end.** Design, frontend, backend, database and deployment, all handled by me.
3. **Use AI as a helper.** I work with AI coding tools like OpenCode and Claude to move faster, and I always test and review the result myself.
4. **Ship and improve.** I deploy on Vercel early, then improve using real feedback and analytics.
5. **SEO from day one.** Sitemap, meta tags, Search Console and Analytics are part of every project I finish.
